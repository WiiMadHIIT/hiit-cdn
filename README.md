# hiit-cdn

##使用方法
1. jsDelivr CDN加速获取github内容： https://cdn.jsdelivr.net/gh/[用户名]/[仓库名]@[版本/分支]/[文件路径]
2. eg. "https://cdn.jsdelivr.net/gh/WiiMadHIIT/hiit-cdn/manuals/Music%20Boxing%20Machine-Beat%20X%20Series-manual-en.pdf"
